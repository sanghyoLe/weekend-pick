이번에는 원본 전체 이미지를 독립된 `figure` 안에 비례 축소·확대하여 표시하고, 자체 설명은 이미지 밖에 둔다. 원본 파일은 다운로드한 그대로 `assets/`에 보존했다. 크롭·필터·합성 오버레이를 허용하는 재사용 템플릿이 아니다. 자동화에서 이미지에 글자를 덮거나 다른 구도로 잘라 쓰려면 해당 이미지의 별도 허락 또는 변경 허용 유형 확인이 필요하다. 원문 작성자·사진 촬영연도가 별도로 확인되지 않은 자료에 임의 저작자명이나 연도를 붙이지 않았다.

## 재생성·검증

프로젝트 루트에서 실행:

```sh
node outputs/instagram/2026-09-14-weekly-v2/render.mjs
```

기존 Playwright와 Chrome만 사용한다. 7장, 1080×1350, JPEG 8MB 미만, 캡션 2,200자 이하, 이미지 로딩·원본 비율·서체 로딩·카드 넘침·푸터 겹침·문자색 대비 4.5:1 이상·320/375/414/768px 미리보기 넘침을 검사한다. 자동 결과는 `qa.json`, 모바일 표지는 `qa-*.png`에 기록한다. ZIP에는 업로드할 이미지와 캡션·출처만 포함한다.

Hallmark 정적 카드 범위 검토: P4 H4 E4 S5 R4 V4. 타이포·색 토큰·크롭 없는 이미지·실제 행사 정보·모바일 미리보기를 검토했다. 웹 내비게이션, 입력 상태, 애니메이션, 페이지별 테마 순환은 정적 이미지 산출물에 해당하지 않는다.
